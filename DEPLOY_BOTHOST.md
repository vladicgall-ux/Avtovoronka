# Установка бота на bothost

Пошаговая инструкция по запуску `main.py` на хостинге bothost. Названия
кнопок в панели могут немного отличаться в зависимости от версии интерфейса
bothost, но общая логика (загрузка проекта → переменные окружения → запуск)
везде одна и та же — ориентируйтесь по смыслу, если конкретный пункт меню
называется иначе.

## 1. Подготовка

Вам понадобятся заранее:
- **Токен Telegram-бота** — получить у [@BotFather](https://t.me/BotFather)
  командой `/newbot` (или `/mybots` → выбрать бота → API Token, если бот уже создан).
- **Ваш Telegram ID** — узнать у бота [@userinfobot](https://t.me/userinfobot)
  (пришлёт число вида `123456789`).
- Zip/файлы проекта: `main.py`, `requirements.txt`, `.env.example`, `README.md`.

## 2. Загрузка проекта в bothost

1. Зарегистрируйтесь / войдите на bothost.
2. Создайте новый проект (обычно кнопка **"Создать проект"** / **"New project"**).
3. Выберите тип **Python**.
4. Загрузите туда файлы проекта — `main.py` и `requirements.txt` обязательны
   (`.env.example` и `README.md` можно не загружать, они не нужны для работы бота).
5. В качестве **главного файла / entry point / стартового скрипта** укажите
   именно `main.py` (это единственный файл с кодом бота — второго "main" в
   проекте нет, поэтому bothost не должен путать его с чем-либо ещё).
6. Команда запуска (если хостинг просит явно указать команду):
   ```
   python main.py
   ```
   (файл сам поднимает и Telegram-бота, и веб-сервер для Instagram — отдельно
   gunicorn запускать не нужно, хотя он и присутствует в `requirements.txt`
   на случай, если панель bothost сама захочет использовать WSGI-обвязку).

## 3. Переменные окружения

В разделе проекта **Переменные окружения / Environment variables / Secrets**
добавьте следующие пары ключ-значение:

| Переменная      | Обязательна | Что это | Пример |
|-----------------|:-----------:|---------|--------|
| `BOT_TOKEN`     | ✅ Да | Токен Telegram-бота от BotFather | `123456789:ABCdefGHIjklMNOpqrsTUVwxyz` |
| `ADMIN_ID`      | ✅ Да | Ваш Telegram ID — без него бот не запустится (админ-панель иначе была бы доступна кому угодно) | `987654321` |
| `PORT`          | ⚠️ Обычно да | Порт, на котором bothost ожидает работающий веб-процесс. Уточните у bothost, какой порт слушать (часто это переменная, которую сам хостинг подставляет автоматически — тогда просто оставьте `PORT`, ссылающуюся на неё, либо укажите значение, которое требует панель) | `5000` |
| `IG_APP_SECRET` | ➖ Нет, но желательно | App Secret вашего приложения в Meta for Developers — включает проверку подлинности вебхуков Instagram и нужен для автопродления токена. Без него бот тоже заработает, но будет доверять любому, кто узнает адрес `/webhook` | `a1b2c3d4e5f6...` |
| `IG_APP_ID` | ➖ Нет, но желательно | App ID из того же раздела Meta for Developers (виден сразу, без «Показать»). Вместе с `IG_APP_SECRET` включает автоматическое продление Instagram-токена — без него токен придётся обновлять вручную | `1234567890123456` |

Ничего из настроек Instagram (токен страницы, кодовое слово, тексты сообщений,
цена курса и т.д.) вводить в переменные окружения **не нужно** — всё это
настраивается прямо в самом Telegram-боте через `/admin` после запуска и
хранится в файле `bot_settings.db`, который бот создаёт сам при первом старте.

## 4. Запуск

1. Сохраните переменные окружения и запустите проект (кнопка **"Запустить" /
   "Deploy" / "Start"**).
2. В логах должно появиться примерно:
   ```
   INFO:root:Flask Webhook Server запущен на порту 5000
   ```
   Если вместо этого видите ошибку `ValueError: Укажите BOT_TOKEN...` или
   `Укажите ADMIN_ID...` — значит соответствующая переменная не сохранилась,
   проверьте раздел переменных окружения ещё раз.
3. Откройте вашего бота в Telegram и отправьте `/start` — должно прийти
   приветственное сообщение с кнопкой оплаты.
4. Отправьте боту `/admin` (вы должны отправлять это с аккаунта, чей ID
   указан в `ADMIN_ID`) — откроется панель управления с кнопками настроек.

## 5. Публичный адрес для вебхука Instagram

Это отдельный вопрос от переменных окружения. После того как проект запущен,
найдите в панели bothost **публичный URL вашего проекта** — обычно он
отображается на странице проекта (что-то вроде `https://имя-проекта.bothost.ru`
или похожий адрес, в зависимости от того, что выдаёт конкретно ваш тариф).

Полный адрес для вебхука — это этот домен + `/webhook`, например:
```
https://имя-проекта.bothost.ru/webhook
```

Этот адрес нужно вставить в настройках вебхука вашего приложения в
[Meta for Developers](https://developers.facebook.com/apps) — подробный
пошаговый разбор настройки самого Instagram (приложение, разрешения,
Verify Token, App Secret) уже есть в `README.md` в разделе
**"⚙️ Настройка Instagram (только через Meta Graph API)"**.

Если в панели bothost нет готового публичного домена (только внутренний
порт) — уточните у поддержки bothost, как получить внешний HTTPS-адрес для
проекта: Meta принимает только `https://`-адреса для вебхуков.

## 6. Частые проблемы

- **Бот не отвечает вообще** — проверьте в логах bothost, не упал ли процесс
  сразу после старта (обычно из-за отсутствующего `BOT_TOKEN`/`ADMIN_ID`).
- **`/admin` не открывается** — убедитесь, что пишете боту с аккаунта, чей
  числовой ID точно совпадает со значением `ADMIN_ID` (не username, а именно
  ID-число).
- **Instagram-комментарии не обрабатываются** — проверьте в боте
  **📋 Текущие настройки**: заполнен ли `Instagram Page Access Token`, и
  сверьте `Verify Token` с тем, что указано в настройках вебхука в Meta.
- **Оплата не работает** — в разделе **📋 Текущие настройки** должно быть
  `ЮKassa Token: Настроен`; если нет — задайте его кнопкой **💳 Токен ЮKassa**.
