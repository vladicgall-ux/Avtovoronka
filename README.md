# All-in-One Bot V5: Кнопка «Меню» слева снизу для Админа

Теперь вам не нужно вручную вводить текст `/admin`. 

## 🚀 Как работает кнопка слева (Bot Menu Button):
- Бот регистрирует персональный скоуп (`BotCommandScopeChat`) специально для вашего `ADMIN_ID`.
- В левом нижнем углу Telegram у вас появляется постоянная синяя кнопка **«Меню»**.
- При нажатии на неё сразу выпадают команды:
  - ⚙️ **Панель управления** — мгновенно открывает админ-кнопки
  - 📋 **Посмотреть настройки** — выводит сводку текущих параметров
  - 🚀 **Перезапуск / Вид клиента** — показать бот глазами покупателя
- Обычные пользователи видят в меню только команду запуска курса.

## ⚙️ Настройка Instagram (только через Meta Graph API)

Бот принимает комментарии из Instagram через официальный вебхук Meta и не требует
ничего, кроме бизнес-аккаунта Instagram, привязанного к Facebook-странице.

1. **Создайте приложение** на https://developers.facebook.com/apps → тип **Business**.
2. В приложении добавьте продукт **Webhooks**, объект **Instagram**.
3. **Callback URL:** `https://ВАШ_ДОМЕН/webhook`
   **Verify Token:** значение, которое вы видите в боте по кнопке
   **🔐 Verify Token (IG)** (или в **📋 Текущие настройки**) — впишите его сюда один в один.
4. Подпишитесь на поле **comments**.
5. В разделе **Settings → Basic** скопируйте **App Secret** и укажите его в `.env`
   как `IG_APP_SECRET` — это включит проверку подписи входящих запросов.
6. Получите **Page Access Token** для страницы, привязанной к вашему Instagram
   (через Graph API Explorer или сгенерированный токен приложения) с разрешениями:
   `instagram_basic`, `instagram_manage_comments`, `instagram_manage_messages`,
   `pages_show_list`, `pages_messaging`. Вставьте его в боте кнопкой **🔑 Instagram Token**.
7. Готово. Когда под вашим постом в Instagram появится комментарий с кодовым словом
   (кнопка **🎯 Кодовое слово IG**), бот пришлёт пользователю Direct-сообщение
   (кнопка **✉️ Текст Direct (IG)**) и, если включено, ответит под самим комментарием
   (кнопка **💬 Ответ под комментом (IG)** — отправьте `-`, чтобы отключить публичный ответ).

Все тексты и токены редактируются прямо в Telegram-боте через `/admin` — без
редеплоя и без правки кода.

## 🔒 Исправленные проблемы и уязвимости (v5.1)

- **Критическая уязвимость доступа:** если `ADMIN_ID` не задан в `.env` (или равен `0`),
  раньше админ-панель была доступна ЛЮБОМУ пользователю бота. Теперь бот отказывается
  стартовать без корректного `ADMIN_ID`.
- **Подделка Instagram-вебхуков:** входящие POST-запросы на `/webhook` никак не
  проверялись на подлинность. Добавлена проверка подписи `X-Hub-Signature-256`
  через `IG_APP_SECRET` (см. настройку выше).
- **Дубли сообщений:** при повторной доставке одного и того же события Meta
  (retry) бот мог несколько раз подряд отправить Direct и ответ под комментарием.
  Добавлена дедупликация по `comment_id`.
- **Эхо-петля:** собственный ответ бота под комментарием тоже прилетал как новое
  событие `comments` и мог повторно обрабатываться. Теперь такие события
  распознаются и игнорируются.
- **Не редактировался ответ под комментарием и Verify Token** — добавлены
  отдельные кнопки в админ-панели.
- **Не было обработки ошибок** при отправке счета на оплату и запросов к Graph API
  Instagram — сбой внешнего сервиса больше не остаётся незамеченным и не роняет бота.
- **Flask-сервер** теперь запускается в многопоточном режиме (`threaded=True`),
  чтобы вебхуки Instagram не блокировали друг друга при параллельных запросах.
